# XplainAI ? UX & Visual Direction

## Visual Philosophy: The Scientific Research Instrument
- **Character**: Calm, authoritative, technical, precise, cinematic.
- **Anti-patterns to avoid**:
  - Generic SaaS template look.
  - Purple/cyan neon glow soup on nested dark cards.
  - Vague "AI confidence" percentages that communicate nothing.
  - Meaningless floating background blobs.
- **Visual Foundation**:
  - Deep carbon/zinc palette with high-contrast monochrome typography.
  - Subdued semantic accent colors: Emerald (Verified Evidence), Amber (Assumption / Unverified), Ruby (Contradiction / Weakness), Cyan (Factual Claim), Violet (Active Research Step).
  - Spatial clarity: generous whitespace, razor-thin borders (1px border-zinc-800), subtle frosted surface blur.

## Motion & Interaction Model (Emil Kowalski Philosophy)
- Motion is earned: only animate when state changes require visual continuity.
- Spring physics: snappy entrances (`stiffness: 300`, `damping: 30`), zero overshoot on technical data panels.
- Spatial continuity: smoothly morph the active execution pipeline into the response structure graph when streaming completes.\n
