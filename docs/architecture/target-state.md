## 3. Flagship Architectural Upgrades
1. **Provider-Neutral Model Capability Gateway**:
   Unified interface accepting capability requirements (`research`, `synthesis`, `fast`, `reasoning`) with pluggable adapters (OpenAI, Anthropic, Gemini, Local/Echo).
2. **Formal Research Pipeline & Ontology**:
   Typed domain entities: `ResearchRun`, `ResearchStep`, `Source`, `Evidence`, `Claim`, `Citation`, `Contradiction`, `Assumption`.
3. **Semantic Graph Engine**:
   Nodes: `SOURCE`, `EVIDENCE`, `CLAIM`, `INFERENCE`, `ASSUMPTION`, `CONCLUSION`.
   Edges: `SUPPORTS`, `CONTRADICTS`, `DERIVED_FROM`, `DEPENDS_ON`, `CONFIRMS`, `WEAKENS`.
4. **Dual 2D/3D Spatial Canvas**:
   - High-performance 3D WebGL Constellation view using Three.js / React Three Fiber for spatial cluster exploration.
   - Precision 2D React Flow view for linear sequence reading.
   - Synchronized bi-directional focus between Answer Text, Graph Nodes, and Source Snippets.
5. **Relational Graph Persistence**:
   Store complete graph topologies, evidence relations, and run metadata in relational storage (SQLite/PostgreSQL) so past sessions retain full interactive explainability.\n
