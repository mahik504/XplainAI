# XplainAI ? Design Principles & Visual System

## 1. The Research Instrument Aesthetic
- **Calm Authority**: High-density information presented with clean Swiss typography, crisp grid alignments, and zero clutter.
- **Color Discipline**: Deep zinc/carbon canvas (`#09090b`, `#18181b`) with purposeful semantic accents.
- **Semantic Color Matrix**:
  - Verified Evidence: Emerald (`#10b981`)
  - Factual Claim: Cyan (`#06b6d4`)
  - Assumption / Unverified: Amber (`#f59e0b`)
  - Contradiction / Weakness: Rose/Ruby (`#f43f5e`)
  - Active Pipeline Stage: Indigo/Violet (`#8b5cf6`)

## 2. Motion System (Emil Kowalski Philosophy)
- Motion is functional, never decorative.
- Fast, physical transitions: Spring easing (`stiffness: 300, damping: 30`) for dialogs and drawers; subtle smooth layout morphs for graph topology transitions.\n
