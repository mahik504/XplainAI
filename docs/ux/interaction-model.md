# XplainAI ? Interaction Model

## 1. Bi-directional Highlighting Protocol
- Hovering or clicking a sentence in the chat response highlights:
  - The corresponding **Claim Node** in the 2D/3D graph canvas.
  - The connected **Evidence Nodes** and **Source Badges**.
  - The exact **Source Snippet** in the inspection panel.
- Clicking a node in the graph conversely highlights the relevant sentence in the chat area and scrolls it into view.

## 2. Keyboard & Accessibility Controls
- `Escape`: Exit claim focus or close inspector drawer.
- `/`: Focus search / message composer.
- `Tab / Shift+Tab`: Navigate between nodes and interactive citations.
- `2` / `3`: Toggle between 2D Flow and 3D Constellation views.\n
